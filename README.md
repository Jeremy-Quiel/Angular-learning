# Aprendizaje sobre Angular framework

## Como iniciar un proyecto:
`ng new (nombre_proyecto)`

## Usar bun para acelerar dependencias:
dentro del proyecto hacer: `rm -rf node_modules`

y despues: `bun install`

## Correr la aplicacion:
`ng serve`

## Construir aplicacion para produccion
`ng build`

## Crear un componenete:
`ng g c (component)`
